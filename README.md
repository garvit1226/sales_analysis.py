# 📊 Company Sales Analysis using NumPy

This is a beginner-friendly mini project built with NumPy to analyze monthly sales data of a company.

## 🚀 Features

* Calculates total yearly sales
* Computes average monthly sales
* Finds highest and lowest sales
* Identifies best and worst performing months
* Lists months above and below average

## 🛠️ Tech Used

* Python
* NumPy

## ▶️ How to Run

1. Install NumPy:

   ```bash
   pip install numpy
   ```
2. Run the script:

   ```bash
   python sales_analysis.py
   ```
3. Enter sales values for each month when prompted.

## 📌 Example Output

* Total Sales
* Average Sales
* Best Month
* Worst Month
* Above/Below Average Months

## 🎯 Purpose

This project helps beginners understand NumPy operations like arrays, aggregation functions, and indexing in a practical way.
